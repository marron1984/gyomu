# A勤 業務チェックリスト（Web版）

DHP 訪問介護サービスの「A勤 業務チェックリスト（行動ベース・全154項目）」を、
スタッフがスマホ／PCのブラウザでチェックできるようにした **静的サイト** です。

サーバーやログインは不要。ページを開いて上から順にチェックするだけで使えます。

## 特長

- **全154項目・6フェーズ**（出勤準備 → ルネッサンス巡回 → パシフィック巡回 → 片付け → 排泄 → 昼食準備）を時系列で表示
- **区分の色分け**：オレンジ＝排泄／緑＝昼食準備／無印（グレー）＝対応
- **部屋・氏名・動作・注意点**を各項目に表示
- **進捗バー**と各フェーズの達成数を表示
- **チェック状態は端末のブラウザに自動保存**。**日付が変わると自動でリセット**（毎日まっさらな状態で開始）
- **担当者名**の入力欄（端末に保存）
- **未完了だけ表示**フィルタ、**リセット**ボタン
- フェーズの見出しをタップで折りたたみ可能

## 構成

ビルド不要のプレーンな HTML / CSS / JavaScript です。

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `styles.css` | スタイル |
| `app.js` | 描画・チェック保存・進捗計算 |
| `data.js` | チェックリストのデータ（全154項目） |
| `vercel.json` | Vercel 用設定 |

## ローカルで確認する

任意の静的サーバーで開けます。例：

```bash
npx serve .
# または
python3 -m http.server 3000
```

ブラウザで `http://localhost:3000` を開きます。

## Vercel へのデプロイ

1. このリポジトリを Vercel にインポート（Add New → Project）
2. フレームワークは「Other（静的）」のまま **Deploy**

ビルド設定や環境変数は不要です。

## チェックリストの改訂

業務内容が変わった場合は `data.js`（`window.CHECKLIST_DATA`）を編集して再デプロイすると反映されます。
各項目は `no`（番号）・`kubun`（区分）・`room`（部屋）・`name`（氏名）・`action`（動作）・`note`（注意点）を持ちます。

## データの保存について

チェック状態は各利用者の **端末のブラウザ（localStorage）** に保存されるため、
端末・ブラウザをまたいだ共有はされません（個人の当日の進捗管理用）。
全スタッフで状態を共有・記録したい場合は、サーバー＋データベース構成への拡張が必要です。
