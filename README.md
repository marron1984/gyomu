# A勤 業務チェックリスト Web版

DHP 訪問介護サービス（ルネッサンス・パシフィック）の「A勤 業務チェックリスト（時系列・全129項目）」を
Web化したアプリです。スタッフが当日の業務をチェックして**完了サイン（用紙の写真）をアップロードして提出**し、
**上司が内容を確認して承認 / 差し戻し**する承認フローを備えています。

## 主な機能

- **チェックリスト入力（スタッフ）**
  - 元の Word と同じ フェーズ1〜6・全129項目を時系列で表示
  - 区分の色分け（オレンジ＝排泄／緑＝昼食準備／無印＝対応）、部屋・氏名・注意点を表示
  - 実施日・担当者・人員（2名／1名）の記入、各項目のメモ、備考・申し送り
  - フェーズごと／全体の進捗バー
  - 参考情報としてデイ送迎表（曜日別）も表示
- **完了サインの提出**
  - サイン済み用紙を**スマホ等で撮影してアップロード**（JPEG/PNG/WebP/HEIC、最大10MB）
- **承認（上司）**
  - 承認待ち／承認済み／差し戻し／すべて でフィルタ
  - チェック内容・メモ・サイン写真を確認し、**承認** または **コメント付きで差し戻し**
- **簡易ログイン**：名前を選択＋パスワード。役割（スタッフ／上司）で画面が切り替わります。

## 技術構成

- Node.js + Express（自己完結型サーバー）
- データ保存：SQLite（`better-sqlite3`）／サイン写真：`uploads/`
- 認証：セッション（`express-session`）＋パスワードハッシュ（`bcryptjs`）
- フロントエンド：静的HTML/CSS/JS（ビルド不要）

## セットアップ

```bash
npm install        # 依存パッケージのインストール
npm run init-db    # 初期ユーザーを作成（下記）
npm start          # サーバー起動（http://localhost:3000）
```

ブラウザで `http://localhost:3000` を開きます。

### 初期ユーザー（`scripts/init-db.js` で作成）

| 名前           | 役割   | 初期パスワード |
| -------------- | ------ | -------------- |
| 上司（管理者） | 上司   | `admin1234`    |
| スタッフA      | スタッフ | `staff1234`  |
| スタッフB      | スタッフ | `staff1234`  |

> ⚠️ 初回ログイン後、ヘッダーの「パスワード変更」から必ず変更してください。
> ユーザーの追加・名前変更は `scripts/init-db.js` の `SEED_USERS` を編集して `npm run init-db` を再実行します
> （既存ユーザーはスキップされます）。

## 環境変数（任意）

| 変数             | 説明                                   | 既定値        |
| ---------------- | -------------------------------------- | ------------- |
| `PORT`           | 待ち受けポート                         | `3000`        |
| `SESSION_SECRET` | セッション署名鍵（本番では必ず設定）   | 起動毎にランダム |

本番運用では `SESSION_SECRET` を固定値で設定し、HTTPS 経由で公開してください。

## データの保存場所

- データベース：`data/app.db`（提出・承認の記録）
- チェックリスト定義：`data/checklist.json`（元Wordから生成。改訂時はここを編集）
- サイン写真：`uploads/`

これらは `.gitignore` で除外しています。バックアップ対象に含めてください。

## チェックリストの改訂

業務内容が変わった場合は `data/checklist.json` を編集すると即時に反映されます
（フェーズ・小見出し・項目No・区分・部屋・氏名・作業内容・注意点を保持）。
